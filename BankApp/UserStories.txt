OBLIGATORISKA UPPGIFTER:

1. Som systemägare vill jag att alla användare ska logga in med ett unikt användarnamn och lösenord.
2. Som administratör på banken vill jag kunna skapa nya användare i systemet.
3. Som systemägare vill jag att användare som misslyckas med inloggningen tre gånger ska låsas ute från att logga in i systemet.
4. Som användare vill jag kunna se en lista med alla mina bankkonton och saldot på dessa.
5. Som användare vill jag kunna föra över pengar mellan två av mina konton.
6. Som användare vill jag kunna föra över pengar till andra kunder i banken.
7. Som användare vill jag kunna öppna upp nya konton i banken.
8. Som användare vill jag kunna ha ett visst konto i en annan valuta.
9. Som bankägare vill jag att överföringar mellan konton med olika valutor växlas enligt rätt växelkurs, vilken uppdateras dagligen av administratören på banken.
10. Som användare vill jag kunna öppna sparkonto i banken och när jag sätter in dem få se hur mycket ränta jag kommer kunna få på pengarna jag sätter in.
11. Som användare vill jag kunna låna pengar av banken och direkt få se hur mycket ränta jag kommer behöva betala på det lånet.
12. Som bankägare vill jag begränsa hur mycket varje kund kan låna av banken så att de maximalt kan låna 5 ggr de pengar de redan har hos banken.
13. Som användare vill jag kunna se en logg på alla överföringar m.m. som skett på mina konton.
14. Som bankägare vill jag att appen ser snygg ut med tydliga menyer, färgsättning och en snygg logga i ASCII art som syns när användaren loggar in.
15. Som bankägare vill jag inte att transaktioner sker direkt när användarna lägger in dem utan i stället var 15:e minut så att vi har kontroll på när de sker.

EXTRA UPPGIFTER:

16. Som systemägare vill jag att varje användare ska kunna uppdatera sina personliga uppgifter (t.ex. e-postadress, telefonnummer).
17. Som bankägare vill jag kunna se statistik om användarnas transaktioner (t.ex. totala belopp överförda, mest populära konton, etc.).
18. Som användare vill jag kunna få notifieringar via e-post eller SMS när stora transaktioner sker (över en viss summa) på mitt konto.
19. Som administratör vill jag kunna sätta regler för hur låneräntor ska beräknas beroende på olika faktorer (t.ex. användarens kreditvärdighet).
